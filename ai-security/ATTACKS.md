# ATTACKS — AI 攻击面地图

> 分类遵循"模型层 / 系统层 / Agent 层"三层视角。具体攻防细节与
> 编号引用以原始论文为准（待考证条目已标注）。

## 一、模型层攻击（针对模型本身）

| 攻击 | 机制 | 代表形态 |
|------|------|---------|
| 越狱 Jailbreak | 绕过对齐约束的提示构造 | DAN 系、角色扮演、加密提示（2023 起爆发） |
| 提示注入 Prompt Injection | 把指令伪装成数据 | 直接注入 / 间接注入（网页、文档、邮件里藏指令） |
| 数据投毒 / 后门 | 训练或微调阶段植入触发词 | 后门触发器、偏好数据污染 |
| 模型提取 | 通过 API 蒸馏能力 | 黑盒查询重建模型行为 |
| 对抗样本 | 输入扰动改变输出 | 图像/文本对抗样本（经典方向） |
| 思维链泄露 | 推理轨迹暴露敏感信息 | CoT 中的隐私与内部思考泄露（2025 起热点） |

## 二、系统层攻击（针对部署与供应链）

- **供应链攻击**：恶意模型权重（如 HuggingFace 上的投毒模型）、
  恶意插件/工具包、依赖劫持
- **数据管线攻击**：检索库投毒（RAG 场景）、训练数据污染
- **模型文件格式攻击**：pickle/序列化反序列化漏洞（经典，待考证具体案例）
- **推理服务攻击**：DoS、侧信道、API 滥用

## 三、Agent 层攻击（agentic 时代的新攻击面）★

Agent 把模型接进了真实世界，攻击面从"输出"扩展到"行动"：

| 攻击 | 机制 |
|------|------|
| **工具调用劫持** | 诱导 agent 调用危险工具（执行代码、转账、删除） |
| **记忆投毒** | 向 agent 的长期记忆注入错误信念，跨会话持久化 |
| **越权链** | 多工具编排中的权限提升（A 工具的输出喂给 B 工具） |
| **目标劫持** | 用户目标被任务执行过程中的注入悄悄替换 |
| **环境攻击** | 沙箱逃逸、浏览器 agent 被恶意网页反向操控 |

Agent 攻击的核心性质：**一次成功的注入 = 一次真实世界的动作**，
损失单位从"一句话"变成了"一笔钱/一次操作"。

## 对我们的意义

我们的系统本身就是 agent 工程（PRDT 8 Agent、dsh-quant 46 工具、
presearch 管线），上面的每一类 agent 攻击都对应我们的一个工程决策：

- 工具契约（schema 先行、权限最小化）——对抗"工具调用劫持"
- 确定性证据链（管道里零 LLM）——对抗"目标劫持"与不可审计行为
- append-only 语料 + 核验门——对抗"记忆投毒"

**安全不是我们的副业，是我们 harness 哲学的必然推论。**
