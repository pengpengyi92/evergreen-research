# INCIDENTS — AI 安全事件编年史

> 只记"改变了行业认知"的事件。年份以公开报道为准，细节待考证处
> 已标注 ⚠。此档案会持续生长。

## 编年

| 年份 | 事件 | 意义 |
|------|------|------|
| 2016 | Tay 聊天机器人被网民"教坏"下线 | 首个大规模公开的对齐失败案例 |
| 2022-2023 | ChatGPT 发布后越狱潮（DAN 等） | 把"越狱"从学术词变成大众词 |
| 2023 | OWASP LLM Application Top 10 发布 | 行业首个 LLM 应用安全风险清单 |
| 2023 | 间接提示注入研究爆发（网页/文档藏指令） | 攻击面从对话扩展到数据 |
| 2024 | 各实验室规模化红队报告（Anthropic 等） | 红队从研究变成工业流程 |
| 2024-2025 | Agent 工具调用攻击演示（转账/删除） | 损失单位从"一句话"变成"动作" ⚠ |
| 2025 | 推理模型思维链泄露与监控讨论 | 推理时计算引入全新安全面 |
| 2025 | OWASP LLM Top 10 更新 | 供应链与 agent 风险入列 ⚠ |

## 三条规律

1. **攻击面随能力扩展**：对话 → 工具 → agent → 推理，每多一层能力，
   就多一层攻击面——安全是能力的影子。
2. **公开事件只是冰山**：产业里的安全事件大多不公开；学术界能
   研究的，是那些"愿意被研究"的部分。
3. **每个事件都在教育市场**：Tay 教育了对齐，越狱潮教育了护栏，
   agent 攻击正在教育权限设计——事件是安全工程最好的老师。
