# BENCHMARKS — AI 安全评测基准清单

> 安全评测的裁判体系。具体数字与排名以各基准官网/论文为准
> （本档案是导引，不是成绩单）。⚠ 标注项待考证。

## 通用越狱/有害内容

| 基准 | 测什么 | 备注 |
|------|--------|------|
| HarmBench | 18 类有害行为的攻防双向评测 | 2024，攻防对称设计 |
| JailbreakBench | 越狱攻击库 + 防御评测 | 2024，标准越狱集 |
| AdvBench | 经典有害指令集 | 早期常用（2023） |
| WildJailbreak | 野外收集的越狱样本 | 覆盖合成与真实分布 |
| SafetyBench（中文） | 中文安全评测 | 中文生态重要补充 ⚠ |

## Agent 安全（我们的重点）

| 基准 | 测什么 | 备注 |
|------|--------|------|
| AgentHarm | agent 在真实工具环境中的有害行为 | 2025 前后 ⚠ |
| AgentDojo | 带工具的 agent 攻防环境 | 模拟攻击/防御交互 |
| CyberSecEval（Meta） | 网络安全能力与风险评测 | 2024 起迭代 |
| ToolEmu / τ-bench 类 | 工具调用正确性与安全性 | 与安全交叉 |

## 推理安全 / 新方向

- **CoT 安全评测**：思维链泄露、推理过程有害性（2025 起热点）
- **多模态安全基准**：图像/视频越狱
- **RAG 投毒评测**：检索库污染下的系统鲁棒性（与我们 RAG 线程
  直接相关——队列）

## 使用原则

1. 基准数字会过期——引用时注明版本与日期
2. "榜单第一"不是安全证明：**攻防是军备竞赛，静态排名会腐烂**
3. 我们自己的系统是"被评测对象"也是"评测基础设施"：presearch
   的审计/核验体系，是研究市场版的安全评测
