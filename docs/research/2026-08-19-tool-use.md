## Findings

### 1. Tool use × self-evolution — the training environment becomes the tool

- **SPADE**: self-play in synthetic executable environments — tool environments as the training ground.
- **RTPO**: reverse-turn policy optimization, stabilizing agentic training.
- **Write, Execute, Refine**: from skill follower to skill optimizer.
- **Policy Iteration with Human Feedback** ([2608.16831](https://arxiv.org/abs/2608.16831)): RL enters tool calling.

Trend (abstract-level): tools are no longer an add-on bolted onto a frozen model — they are the environment in which agents self-evolve. This is the direction most directly relevant to the program's recursion theme.

### 2. Tool use × least privilege — safety as a design item

- **Task-Conditioned Least-Privilege Learning**: task-conditioned least-privilege learning.
- **SkillEffect**: checked lowering for memory-constrained agent tools.
- **When Agents Act on Web3**: an attack-surface survey of MCP / skills.

This echoes the program's public ai-security track: least privilege is moving from an engineering principle to a formal research topic.

### 3. Tool use × auditability — the trace as evidence

- **LEDGER**: claim-to-evidence trace graphs for auditing LLM agents.
- **Auditing Self-Evolution in Financial Agents**: capability gains of financial agents, and their audit — the report flags this as the program's precise three-way intersection: Quant × Tool × Recursion.

Trend (abstract-level): tool-call traces are becoming audit infrastructure. The frontier is converging on the same trace-as-evidence principle that the P-Research program's harness practice has followed.

### 4. Compositional tool calling

- **Looped Language Models Improve Compositional Tool Calling**: the orchestration problem of multi-step tool chains.
